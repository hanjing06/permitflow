```python
def two_pass_match(anchors: pd.DataFrame, candidates: pd.DataFrame) -> list[dict]:
    """
    Returns a list of cluster records (the contents of clusters.json).
    Each record has shape (see SCHEMAS.md):
      {
        "cluster_id": str,                 # "anchor-<src>-<id>" for piggyback, "merge-<n>" for merges, "singleton-<src>-<id>" for singletons
        "tag": "piggyback" | "merge" | "singleton",
        "anchor": {source, permit_id, street_label, start_date, end_date, geom_wkt} | null,
        "members": [
          {source, permit_id, street_label, work_type, start_date, end_date, lon, lat}
        ],
        "merged_window": {start_date, end_date},
        "permits_in_record": int,           # always len(members) — used by metrics.json
        "excavations_avoided": int          # piggyback: len(members), merge: len(members)-1, singleton: 0
      }
    """
```

Implementation:

**Pass 1 — anchor matching (piggyback):**
1. For each candidate with non-null `lon`/`lat`:
   - Project candidate to (cx_m, cy_m) using LAT/LON_M_PER_DEG.
   - For each anchor: project to (ax_m, ay_m). Compute euclidean distance in meters.
   - Compute temporal overlap: `delta_days = max(0, max(c.start, a.start) - min(c.end_or_start, a.end_or_start)).days` — but simpler: the candidate window `[c_start, c_end_or_start+1d]` and anchor window `[a_start, a_end]` are "close in time" if `c_start <= a_end + TIME_DAYS AND c_end_or_start >= a_start - TIME_DAYS`.
   - If `dist <= SPACE_M` AND time-windows are within `TIME_DAYS`, candidate is eligible to piggyback onto this anchor.
   - Pick the anchor with the smallest distance (ties broken by smallest temporal gap).
2. Append the candidate to that anchor's `members` list. The anchor itself is NOT in `members` — it's in `record.anchor`.
3. Any anchor that gathered ≥1 piggyback candidate emits a `tag="piggyback"` record. Anchors with zero candidates do NOT emit records (we only care about anchors that pulled work in).

**Pass 2 — leftover clustering (merge):**
1. Collect all candidates that were NOT matched in Pass 1 AND have geometry.
2. Build feature matrix `[x_m, y_m, t_m]` where `t_m = (start_date - epoch_start).days * TIME_M_PER_DAY`.
3. Run `DBSCAN(eps=DBSCAN_EPS_M, min_samples=DBSCAN_MIN).fit(features)`.
4. For each label `>= 0`, emit a `tag="merge"` record. `cluster_id = f"merge-{label}"`. No anchor. `members` = the candidates in that label.

**Pass 3 — singletons (D-28/D-29):**
1. Any candidate not matched in Pass 1 AND assigned label -1 in Pass 2 (or with no geometry, so it never entered DBSCAN) emits a `tag="singleton"` record. `cluster_id = f"singleton-{source}-{permit_id}"`. Members list contains just that one candidate. `excavations_avoided = 0`.
2. Also emit a singleton record for each ANCHOR that gathered zero piggybacks — but tag those `tag="anchor-only"` instead (they're real planned closures with no piggyback opportunity; Phase 4 may render them as a third color). `excavations_avoided = 0`. Members contains the anchor's own row promoted into the members list so the UI has something to render.

Total invariant: `sum(len(record.members) for record in result) + sum(1 for record in result if record.tag == 'anchor-only')` covers every input row from anchors + candidates exactly once. Add an assert at the end of `two_pass_match()` verifying this.

```python
def load_clusters_json():
    path = os.path.join(os.path.dirname(__file__), "..", "data", "clusters.json")
    if not os.path.exists(path):
        return []
    with open(path) as f:
        return json.load(f)

def get_metrics_from_clusters():
    records = load_clusters_json()
    permits_considered = sum(r["permits_in_record"] for r in records) + sum(1 for r in records if r.get("anchor"))
    excavations_avoided = sum(r["excavations_avoided"] for r in records)
    return {
        "permits_considered": int(permits_considered),
        "excavations_avoided": int(excavations_avoided),
        "by_tag": {
            tag: sum(1 for r in records if r["tag"] == tag)
            for tag in ("piggyback","merge","singleton","anchor-only")
        },
    }
```
