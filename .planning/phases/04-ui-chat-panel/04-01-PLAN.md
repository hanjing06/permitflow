Cache results in a module-level dict keyed by the permit text so repeated /retrieve calls are fast. Rank by cosine similarity to the query embedding. Return top `top_k` permits with `relevance_score` injected.
   - **Optimization escape hatch:** if `len(permits) > 200`, skip embedding all permits and fall back to keyword scoring (avoid embedder hammering during demo).

5. `def lookup_conflict_edges(street_names: list[str], conflict_graph: list[dict]) -> list[dict]`:
   - Return edges whose `shared_streets` intersect `street_names` (case-insensitive). Cap at 10.

6. `def extract_street_mentions(query: str, permits: list[dict]) -> list[str]`:
   - Build a set of unique street names from the permits list. Return the subset that case-insensitively appears as a substring in `query`. Cap at 5.

7. `def build_chat_messages(query: str, context_permits: list[dict], conflict_edges: list[dict], metrics: dict | None) -> list[dict]`:
   - Compose the OpenAI `messages` array. System prompt = existing `SYSTEM_PROMPT` + a `<context>` block listing the retrieved permits (id, street, work_type, dates, status, optimization_status), any conflict edges (permit_a vs permit_b on shared_streets), and headline metrics (permits_considered, excavations_avoided, cost_avoidance). Cap the context block at ~3000 chars (truncate permit list if needed).
   - User message = the raw query.

8. `def stream_chat(query: str, context_permits: list[dict], conflict_edges: list[dict], metrics: dict | None) -> Iterator[str]`:
   - POST to `OLLAMA_URL` with `messages = build_chat_messages(...)`, `temperature: 0.2`, `max_tokens: 800`, `stream: True`. Use `requests.post(..., stream=True, timeout=120)`.
   - Iterate over `response.iter_lines()`. For each line starting with `b"data: "`:
     - If payload is `b"[DONE]"` → break.
     - Otherwise `json.loads` it, pull `choices[0].delta.content`, and `yield` it (skip empty strings).
   - On `requests.RequestException` (Ollama unreachable): yield a single string `"[chat unavailable — Ollama is offline. Demo fallback: the optimizer found {excavations_avoided} excavations to avoid on the hero block.]".format(...)` using `metrics` if present, then return. Never raise.

```python
@app.post("/retrieve")
def retrieve(req: RetrieveRequest):
    permits = load_artifact_or_build(
        "optimized.json" if req.view == "optimized" else "naive.json"
    )
    hits = retrieve_permits(req.query, permits, top_k=req.top_k)
    used_embedder = embed_query("__healthcheck__") is not None
    return {
        "query": req.query,
        "view": req.view,
        "used_embedder": used_embedder,
        "top_k": req.top_k,
        "results": hits,
    }
```

Endpoint 2 — `POST /chat`:
```python
@app.post("/chat")
def chat(req: ChatRequest):
    permits = load_artifact_or_build(
        "optimized.json" if req.view == "optimized" else "naive.json"
    )
    context_permits = retrieve_permits(req.query, permits, top_k=5)
    try:
        conflict_graph = load_artifact_or_build("conflict-graph.json")
    except Exception:
        conflict_graph = []
    streets = extract_street_mentions(req.query, context_permits)
    edges = lookup_conflict_edges(streets, conflict_graph) if streets else []
    try:
        metrics = load_artifact_or_build("metrics.json")
    except Exception:
        metrics = None

    def event_stream():
        # SSE framing: each chunk is `data: <text>\n\n`. We escape newlines so
        # multi-line model output stays a single SSE event for simple client parsing.
        for chunk in stream_chat(req.query, context_permits, edges, metrics):
            safe = chunk.replace("\r", "").replace("\n", "\\n")
            yield f"data: {safe}\n\n"
        yield "data: [DONE]\n\n"

    return StreamingResponse(
        event_stream(),
        media_type="text/event-stream",
        headers={
            "Cache-Control": "no-cache",
            "X-Accel-Buffering": "no",
        },
    )
```
