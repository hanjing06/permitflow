Notes for the executor:

1. Use whatever Python environment the nix flake's `default` mode provides (per CONTEXT "Claude's Discretion" block — env management is open). If `python` resolves to a venv without `pandas`/`requests`, fall back to `nix develop -c python backend/open_toronto.py all` or `nix run .#default -- python backend/open_toronto.py all`. Pick the first that works; don't spend more than ~5 minutes on env yak-shaving.

2. The downloader uses `pd.read_csv(resource_url)` on each CKAN resource. Some Toronto Open Data CKAN resources publish both CSV and GeoJSON; the script grabs the first format in `("csv", "geojson", "json")`. If a dataset arrives only as GeoJSON and `pd.read_csv` fails on it, that dataset will print `failed: ...` and be skipped — log which ones, then **retry just those by editing the resource picker to prefer GeoJSON**:

   ```python
   # in download_dataset(), change the resource ordering preference:
   resources = sorted(resources, key=lambda r: 0 if r.get("format","").lower() == "geojson" else 1)
   ```

   For a GeoJSON resource, read with `requests.get(url).json()` then flatten features into a DataFrame (one row per feature, with a `geometry` column holding the geometry dict as JSON text, mirroring how `road_reconstruction` already stores it). Write to the same `<name>.csv` output path.

3. **Per D-79 rationale (CONTEXT body):** `utility_cuts` and `building_permits` are the load-bearing CANDIDATES; `road_resurfacing` and `sidewalk_construction` are load-bearing ANCHORS. If any of these four fail download after the GeoJSON-fallback retry, **stop and surface the failure** — Plan 01-02 cannot select a hero block without them. `watermain_breaks` and `road_restrictions` are CONTEXT-tier; if they fail, log the failure and continue (Plan 01-02 doesn't depend on them).

4. Do not modify the downloader's defaults beyond the optional GeoJSON-preference patch above. Anything more ambitious belongs in a Phase 3 plan.

5. After the pull, print a one-line summary per file: `name | rows | first_geom_token` (e.g. `utility_cuts | 18432 | Point`) so the developer can eyeball the haul. A trivial inline script using `pandas` is fine.
